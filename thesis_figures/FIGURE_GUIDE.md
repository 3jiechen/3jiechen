# 论文插图素材包说明

本目录提供了 5 张可直接插入毕业论文正文的 SVG 矢量图，适合在 Word、WPS、Typora 或 LaTeX 中使用。

## 文件清单

1. `01_overall_pipeline.svg`
   - 建议章节：第 1 章绪论末尾 / 第 4 章开头
   - 推荐图题：**图 4-1 水声信号识别总体流程图**
   - 作用：概括从 `.mat` 波形、固定长度、STFT 双通道特征、时频双分支融合，到 AWGN 评测和树莓派部署的完整路线。

2. `02_stft_dual_channel.svg`
   - 建议章节：第 3 章数据集与预处理
   - 推荐图题：**图 3-2 STFT 双通道特征构造示意图**
   - 作用：说明 4096 点波形如何映射为 `(2, 64, 64)` 的幅度/相位双通道时频张量。

3. `03_fusion_model.svg`
   - 建议章节：第 4 章识别模型设计与实现
   - 推荐图题：**图 4-4 FusionRNNResNet 时频融合模型结构图**
   - 作用：突出 BiLSTM 时域分支、ResNet18 谱域分支以及 concat 融合分类器之间的关系。

4. `04_awgn_cross_condition.svg`
   - 建议章节：第 5 章实验与结果分析
   - 推荐图题：**图 5-3 AWGN 跨条件评测流程图**
   - 作用：介绍噪声注入、SNR 设置、模型推理、指标统计和 SNR-性能曲线分析逻辑。

5. `05_raspberrypi_deployment_ui.svg`
   - 建议章节：第 6 章树莓派嵌入式部署与人机界面设计
   - 推荐图题：**图 6-2 树莓派部署与 UI 设计示意图**
   - 作用：体现边缘端软件架构与 UI 交互布局，适合“工程展望”或“系统实现方案”部分。

## 使用建议

- 如果学校论文模板支持矢量图，优先插入 SVG；若 Word 兼容性一般，可先导出为 PNG 再插入。
- 图注可统一采用“图 X-X + 名称”的格式，正文中按“如图 X-X 所示”进行引用。
- 若想与学校配色统一，可把 SVG 用浏览器打开后截图，或者在 Figma / Illustrator / Inkscape 中二次修改。
- 若你后面补充了真实实验结果，我建议再追加两类图：
  - 混淆矩阵图
  - 不同模型的训练/验证准确率曲线
